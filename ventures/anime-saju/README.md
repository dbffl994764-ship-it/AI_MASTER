# 별빛도사 · K-SAJU

모바일 우선 정적 웹앱입니다. 서버·유료 API·트래커 없이 GitHub Pages 하위 경로에서 실행되도록 모든 리소스를 상대 경로로 연결했습니다.

## 현재 기능

- 생년월일·출생 시간·출생 국가/도시 입력 → 브라우저 사주 엔진 계산
- 연애·사랑·궁합·재물·직업·학업·오늘의 운세 주제 선택
- 준비 질문 30개와 직접 질문 입력 → 키워드 분류 → 일간별 회사 작성 답변 선택
- 오리지널 SVG 도사의 말풍선 타이핑, 입 애니메이션, 표정 변화
- 결과 저장(로컬 최대 10건), 다시 묻기, 공유 문구 복사
- 한국어·영어 답변 라이브러리 및 오락 목적 고지

## 실행

정적 서버에서 `index.html`을 엽니다. 예: `python -m http.server` 후 `http://localhost:8000/` 접속.

`data/answers.ko.json`·`data/answers.en.json`은 `_docs/1023_B13` 기반의 교체 가능한 콘텐츠입니다. 브라우저에서 `file://`로 직접 열면 JSON `fetch`가 제한될 수 있으므로 정적 서버를 사용하세요.

## 확인 필요

사주 절기 계산의 기준·Gemini 캐릭터 에셋의 상업적 이용 조건·번역 품질·개인정보/운세 고지의 법률 검토·결제·실제 GitHub Pages/휴대폰 화면 QA는 대표 확인이 필요합니다. 실제 배포·결제·외부 게시·계정 가입은 수행하지 않았습니다.

## 이번 QA에서 남은 문제

- 이 실행 환경에서는 브라우저 탭이 제공되지 않아 360px·태블릿의 실제 픽셀 화면과 브라우저 콘솔 0건을 직접 확인하지 못했습니다. 대표는 정적 서버 또는 GitHub Pages에서 `index.html`을 열어 확인해야 합니다.
- `tests.html`의 사주 엔진 기준은 통과했지만, 절기 근사 계산과 KASI 원본 일치 여부는 여전히 확인 필요입니다.
- 영어 답변은 MVP 초안이므로 글로벌 공개 전 원어민 검수가 필요합니다.
- Gemini 캐릭터 생성 결과의 상업적 이용·변환·스토어 배포 조건, 결제 정책과 실제 결제 연동은 대표 확인 전까지 미정입니다.
